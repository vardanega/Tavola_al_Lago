# Tavola al Lago

Responsive restaurant landing page concept for a contemporary Italian osteria in Lecco.

## Features

- Responsive navigation
- Interactive seasonal menu
- Reservation form with client-side validation and confirmation state
- Accessible keyboard and reduced-motion support
- Location and opening-hours section

## Stack

- Semantic HTML5
- CSS3
- Vanilla JavaScript

## Run locally

Open `index.html` directly or serve the directory with any static server.

## Status

Personal concept project. Restaurant identity, address, menu and reservation data are fictional.
